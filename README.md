One emoji for one dream vacation: a desert island 🏝️. A tiny Python program that writes a single emoji to `/output/entry.txt` for make.fun's "One Emoji, One Dream Vacation" bounty.

Why the desert island: it plainly names a dream vacation, it is a postcard at a glance — palm, sand and sea in one glyph — it points at one particular fantasy (castaway paradise) rather than any holiday, and it reads instantly on every screen at any size.

## Run it

```sh
python3 main.py
```

This writes 🏝️ (7 bytes of UTF-8, no trailing newline) to `/output/entry.txt`, deterministically: every run produces byte-identical output.
